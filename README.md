# Violet Finance

Finance forms (PTR, JAR, Advance, Journal...), transaction numbers, projects and budget lines, received payments and
reports for Violet Organization (Menekşe Derneği). Laravel 13 · PHP 8.3 · MySQL/MariaDB · Blade + Alpine.js.
