# Violet Finance

Finance forms, approvals, advances and received payments for Violet Organization (Menekşe Derneği).
Laravel 13 · PHP 8.3 · MySQL.

- **Updating the server:** [SERVER_AR.md](SERVER_AR.md) — the `violet` command (`violet update test`, `violet promote`, `violet rollback live`).
- **Fresh install on a new server:** [DEPLOY_AR.md](DEPLOY_AR.md).

Never run `php artisan db:seed` on a server that already has data.
